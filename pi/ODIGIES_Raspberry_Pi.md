# 🌬 AirSense σε Raspberry Pi — Οδηγίες βήμα-βήμα

> **Νέο όνομα:** το ALU HygroLink λέγεται πλέον **AirSense**. Αν έχεις ήδη το παλιό στο Pi, απλά τρέξε τον νέο
> installer: μεταφέρει μόνος του δεδομένα (`~/hygrolink-data` → `~/airsense-data`), κωδικούς, PIN, πόλη και αισθητήρες.
> Η παλιά εντολή `hygrolink` συνεχίζει να δουλεύει (= `airsense`), και το Pi διαβάζει και το παλιό `hygrolink-wifi.txt`.
> Το όνομα του Pi στο δίκτυο **δεν αλλάζει** — αν το είχες `hygrolink`, συνεχίζεις με `ssh pi@hygrolink.local`.

**Πακέτο 1.6.0** (εφαρμογή v1.6.0 + εργαλείο WiFi + WiFi από κάρτα SD) · Nikolaos K. Paridis (aka nikkpap) · ALU DEV TEAM

Το Raspberry Pi γίνεται ο **μόνιμος server** του AirSense: καταγράφει τον αισθητήρα 24/7, κρατά CSV/XML, στέλνει email, και το βλέπεις από το κινητό (web σελίδα ή εφαρμογή Android), τοπικά ή από παντού με Tailscale. Ο υπολογιστής μπορεί να μένει κλειστός.

---

## 1. Τι χρειάζεσαι
| | |
|---|---|
| Raspberry Pi | **Zero 2 W** (ή 3 / 4 / 5) |
| Κάρτα microSD | 16 GB ή μεγαλύτερη, **A1/A2** (π.χ. SanDisk/Samsung) |
| Τροφοδοτικό | 5 V / 2.5 A, micro-USB για το Zero 2 W |
| WiFi | **2.4 GHz** — το Zero 2 W και ο αισθητήρας δεν βλέπουν 5 GHz |
| Υπολογιστής | Windows με το **Raspberry Pi Imager** (raspberrypi.com/software) |

---

## 2. Προετοιμασία κάρτας (μία φορά)
1. Άνοιξε το **Raspberry Pi Imager**.
2. **Device:** Raspberry Pi Zero 2 W.
3. **OS:** *Raspberry Pi OS (other)* → **Raspberry Pi OS Lite (64-bit)** (χωρίς γραφικό περιβάλλον).
4. **Storage:** η κάρτα SD → **Next** → **Edit settings**:
   - **Hostname:** `airsense`
   - **Username / Password:** π.χ. `pi` και έναν κωδικό που θα θυμάσαι
   - **Wireless LAN:** όνομα και κωδικός του WiFi σου (**2.4 GHz**), χώρα **GR**
   - **Locale:** Europe/Athens
   - Καρτέλα **Services:** ✅ **Enable SSH** → *Use password authentication*
5. **Save → Yes** και περίμενε να γραφτεί η κάρτα.
6. Βάλε την κάρτα στο Pi και δώσε ρεύμα. Περίμενε **2–3 λεπτά** την πρώτη φορά.

---

## 3. Εγκατάσταση — ο εύκολος τρόπος (από Windows)
1. Αποσυμπίεσε το `AirSense-Pi_v1.5.0.zip` σε έναν φάκελο.
2. Κάνε διπλό κλικ στο **`install_from_windows.bat`**.
3. Γράψε **όνομα** (Enter = `airsense.local`) και **χρήστη** (π.χ. `pi`).
4. Δώσε τον **κωδικό του Pi** όταν σου ζητηθεί (2 φορές). Την πρώτη φορά απάντα `yes` στην ερώτηση για «fingerprint».
5. Απάντησε στις ερωτήσεις του installer:
   - **Κωδικός διαχειριστή** → για τις ρυθμίσεις από web/κινητό (βαθμονόμηση, email…)
   - **PIN** → προστατεύει τη σελίδα/εφαρμογή (προτείνεται)
   - **Πόλη** → για τον καιρό (π.χ. `Αμύνταιο`). Αν την αφήσεις κενή, θα βρεθεί από την IP.
   - **Tailscale** → `Ν` για πρόσβαση από παντού: άνοιξε τον σύνδεσμο που εμφανίζεται και συνδέσου με τον **ίδιο λογαριασμό** με το κινητό.
6. Στο τέλος εμφανίζεται **QR** στο παράθυρο: σκάναρέ το με το κινητό. ✅

> Αν το `airsense.local` δεν βρίσκεται, γράψε την **IP** του Pi (τη βλέπεις στη σελίδα του router, στη λίστα συσκευών «airsense»).

### Εναλλακτικά — χειροκίνητα (PowerShell)
```powershell
scp install_pi.sh airsense_wifi.py AirSense_v1.6.0.pyw pi@airsense.local:~/
ssh pi@airsense.local
bash install_pi.sh
```

---

## 4. Ο αισθητήρας
- Ο αισθητήρας πρέπει να είναι στο **ίδιο WiFi** με το Pi. Το Pi τον βρίσκει **αυτόματα** μέσα σε 1–2 λεπτά.
- **Καινούριος αισθητήρας:** σύνδεσέ τον πρώτα στο WiFi από το **AirSense στα Windows** (🧙 Οδηγός) ή από την εφαρμογή wBox της BleBox.
- Αν δεν βρεθεί: στο Pi γράψε `airsense add 192.168.1.50` (η IP του αισθητήρα).

---

## 5. Κινητό
- **Web:** άνοιξε τη διεύθυνση από το QR (π.χ. `http://192.168.1.20:8765`). Στο μενού του browser πάτα «Προσθήκη στην αρχική οθόνη».
- **Εφαρμογή Android (AirSense):** Ρυθμίσεις → **Σκανάρισμα QR** → Δοκιμή & αποθήκευση.
- **Από παντού (4G):** Tailscale στο Pi και στο κινητό με τον ίδιο λογαριασμό → διεύθυνση `http://100.x.y.z:8765`.
- Το QR ξαναβγαίνει με: `airsense qr`

### Ρυθμίσεις χωρίς οθόνη
Στη web σελίδα → **🔐 Ρυθμίσεις διαχειριστή**:
- 📍 Τοποθεσία καιρού
- ➕ Προσθήκη αισθητήρα με IP
- ⏱ Συχνότητα μέτρησης
- ✉ **Email (SMTP)**: Gmail με «Κωδικό εφαρμογής» → Αποθήκευση → Δοκιμή
- 🔑 PIN
- 🔐 Κωδικός διαχειριστή

Στην εφαρμογή Android → **Διαχείριση**: ειδοποιήσεις ορίων, αλλαγή WiFi αισθητήρα, βαθμονόμηση.

## 6. Εντολές στο Pi (μέσω `ssh pi@airsense.local`)
| Εντολή | Τι κάνει |
|---|---|
| `airsense status` | κατάσταση, αισθητήρες, διευθύνσεις |
| `airsense qr` | QR για το κινητό |
| `airsense logs` / `airsense live` | καταγραφή (live: συνεχής, Ctrl+C) |
| `airsense restart` | επανεκκίνηση server |
| `airsense set-admin` | κωδικός διαχειριστή |
| `airsense set-pin 1234` | PIN (χωρίς αριθμό = αφαίρεση) |
| `airsense add 192.168.1.50` | προσθήκη αισθητήρα |
| `airsense city "Αμύνταιο"` | τοποθεσία καιρού |
| `airsense update` | νέα έκδοση (βάλε το `AirSense_vX.pyw` στο `~`) |
| `airsense backup` | αντίγραφο ασφαλείας δεδομένων |
| `airsense wifi` | WiFi του Pi: σάρωση, νέο δίκτυο, αποθηκευμένα |
| `airsense tailscale` | εγκατάσταση/σύνδεση Tailscale |
| `airsense uninstall` | απεγκατάσταση (τα δεδομένα μένουν) |

**Δεδομένα:** `~/airsense-data/` (`airsense.db`, `config.json`, `daily/*.csv|xml`).
Τα αντιγράφεις στα Windows με:
`scp -r pi@airsense.local:~/airsense-data/daily .`

## 7. Αλλαγή WiFi / μεταφορά του Pi αλλού

### 🅰 Ο πιο εύκολος τρόπος: μέσω κάρτας SD (χωρίς SSH)
1. Κλείσε το Pi (βγάλε το ρεύμα) και βάλε την κάρτα SD στον υπολογιστή. Εμφανίζεται δίσκος **bootfs**.
2. AirSense → **⚙ Ρυθμίσεις → 🥧 Raspberry Pi → «📶 WiFi στην κάρτα SD του Pi…»**.
3. **«📶 WiFi αυτού του υπολογιστή»** (παίρνει όνομα και κωδικό από τα Windows) ή γράψε τα με το χέρι → **➕ Προσθήκη** (όσα δίκτυα θες).
4. **💾 Γράψε στην κάρτα SD** → Εξαγωγή κάρτας → στο Pi → ρεύμα.
5. Σε 1–2 λεπτά: `ssh pi@airsense.local`

Ο κωδικός **σβήνεται αυτόματα** από την κάρτα μόλις εφαρμοστεί. Στο `airsense-wifi-log.txt` της κάρτας γράφεται **σε ποιο WiFi μπήκε και η IP** του Pi.
Χωρίς το πρόγραμμα: αντίγραψε το `airsense-wifi.example.txt` της κάρτας ως `airsense-wifi.txt` και συμπλήρωσέ το με το Σημειωματάριο.
> Χρειάζεται να έχει τρέξει **μία φορά** ο installer **v1.5.2+** (όσο το Pi είναι στο σπίτι). Ένδειξη ότι υπάρχει η υπηρεσία: η κάρτα έχει το αρχείο `airsense-wifi.example.txt`.

### 🅱 Με SSH (όσο το Pi είναι ακόμα στο ίδιο δίκτυο)
Με SSH στο Pi (`ssh pi@airsense.local`) γράψε:
```
airsense wifi
```
Ανοίγει μενού:
```
  1) 🔍 Σάρωση & προσθήκη νέου WiFi
  2) 📋 Αποθηκευμένα δίκτυα
  3) ⭐ Προτεραιότητα δικτύου
  4) 🗑  Διαγραφή αποθηκευμένου δικτύου
  5) ✍  Κρυφό δίκτυο
  6) 📶 Κατάσταση / IP
```
- **1** → διάλεξε αριθμό δικτύου → γράψε κωδικό → **«1) Μόνο αποθήκευση»**. Το Pi **θυμάται όλα τα δίκτυα** και συνδέεται μόνο του σε όποιο βρει όταν το πας εκεί. Πρόσθεσε από πριν όσα θες: σπίτι, εργοτάξιο, γραφείο.
- **«2) Σύνδεση ΤΩΡΑ»**: αν το νέο WiFi δεν δουλέψει (π.χ. λάθος κωδικός), το Pi **γυρίζει μόνο του στο προηγούμενο** σε ~1 λεπτό. Το SSH κόβεται αν ο υπολογιστής δεν είναι στο ίδιο νέο WiFi.
- Γρήγορα, χωρίς μενού: `airsense wifi add "Όνομα WiFi" "κωδικός"`
- **Μην ξεχάσεις τον αισθητήρα:** πρέπει να πάει κι αυτός στο ίδιο WiFi (εφαρμογή Android → Διαχείριση → Αλλαγή WiFi, ή .pyw → 🔁 Αλλαγή WiFi).
- **Το μετέφερες χωρίς να το ρυθμίσεις;** Άνοιξε hotspot στο κινητό με **ίδιο όνομα και κωδικό** με ένα δίκτυο που ξέρει το Pi (2.4 GHz), συνδέσου με SSH και τρέξε `airsense wifi`.

## 8. Μεταφορά ιστορικού από τον υπολογιστή (προαιρετικό)
1. Κλείσε το AirSense στα Windows (δεξί κλικ στο 🌬 κάτω δεξιά → Έξοδος).
2. Στο Pi: `airsense stop`
3. Σε PowerShell, από τον φάκελο `Documents\AirSense`:
   `scp airsense.db config.json pi@airsense.local:~/airsense-data/`
4. Στο Pi: `airsense start`

> Μην τρέχουν **ταυτόχρονα** ο υπολογιστής και το Pi ως server, για να μη γράφονται διπλές μετρήσεις. Αν θες το παράθυρο στα Windows μόνο για προβολή, χρησιμοποίησε τη web σελίδα του Pi.

---

## 9. Αν κάτι δεν πάει καλά
| Πρόβλημα | Λύση |
|---|---|
| Δεν βρίσκω το Pi | Περίμενε 3′ μετά το ρεύμα· δοκίμασε την IP από τον router· έλεγξε ότι το WiFi στο Imager ήταν σωστό (2.4 GHz) |
| Δεν βρίσκει τον αισθητήρα | Ίδιο WiFi; `airsense add IP` · `airsense logs` |
| Λάθος πόλη στον καιρό | Με **Starlink** η IP δείχνει άλλη χώρα → `airsense city "Πόλη"` |
| Δεν ανοίγει από 4G | `airsense tailscale`· Tailscale ενεργό και στο κινητό |
| Email δεν στέλνει | Gmail: χρειάζεται 2-Step Verification + **App Password** |
| Κόλλησε | `airsense restart` ή βγάλε-βάλε ρεύμα (ξεκινά μόνο του) |

💡 Για μεγαλύτερη ζωή της κάρτας: καλή κάρτα A1/A2, σταθερό τροφοδοτικό, και `airsense backup` πότε-πότε.
