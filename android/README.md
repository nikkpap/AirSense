# 🌬 AirSense (Android) v1.2.0

Εφαρμογή Android για το **ALU AirSense** (BleBox humiditySensor).
Developer: **Nikolaos K. Paridis (aka nikkpap)** · ALU DEV TEAM

## Τι κάνει
- **Αρχική:** τρέχων καιρός Open-Meteo + πρόγνωση 7 ημερών, κάρτες αισθητήρων (θερμοκρασία, υγρασία, σημείο δρόσου), γράφημα με εξωτερικές τιμές και βροχή/χιόνι (άγγιγμα = τιμές), λήψη CSV/XML.
- **Ειδοποιήσεις:** όρια θερμοκρασίας/υγρασίας, αισθητήρας offline, υπολογιστής εκτός, βροχή/χιόνι/καταιγίδα, παγετός, προώθηση ⚠ από τον υπολογιστή. Έλεγχος στο παρασκήνιο (15′+) ή **ζωντανή παρακολούθηση** με μόνιμη ειδοποίηση.
- **Διαχείριση:** μέτρηση/σάρωση/email, μετονομασία, ενεργοποίηση, αλλαγή WiFi ή αφαίρεση αισθητήρα, τοποθεσία καιρού (αυτόματα από τον υπολογιστή ή αναζήτηση), ρυθμίσεις υπολογιστή, **🔐 βαθμονόμηση** με τον κωδικό διαχειριστή.
- **Ρυθμίσεις:** σύνδεση (QR), Ελληνικά/English, θέμα, Material You.

## Απαιτήσεις
- Στον υπολογιστή: **ALU AirSense** (πρώην ALU HygroLink) v1.4.1+ — για τη διαφορά μέσα–έξω με δικά σου λεκτικά: **v1.5.8+**.
- Android 8.0+ (API 26).

## Άνοιγμα στο Android Studio
1. Αποσυμπίεσε το zip → **File → Open** → φάκελος `android` του repo.
2. Περίμενε το Gradle Sync (κατεβάζει μόνο του ό,τι χρειάζεται).
   Αν προτείνει αναβάθμιση AGP/Kotlin, μπορείς να την αποδεχτείς.
3. **Run ▶** στο κινητό, ή **Build → Build APK(s)**.
   Το release APK υπογράφεται με το debug κλειδί, ώστε να εγκαθίσταται αμέσως.

## Πρώτη σύνδεση
1. Στον υπολογιστή: ALU AirSense → καρτέλα **📱 Κινητό**.
2. Στο κινητό: **Σκανάρισμα QR** → σκάναρε «Τοπικό δίκτυο» (και «Tailscale» για πρόσβαση από παντού).
3. **Δοκιμή & αποθήκευση** → **Συνέχεια**.

Εκδόσεις: AGP 8.11.1 · Kotlin 2.2.0 · Gradle 8.14.3 · compileSdk 36 · Compose BOM 2025.06.00
